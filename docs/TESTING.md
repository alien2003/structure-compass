# Ручная проверка / Manual test checklist

Чек-лист для проверки в игре. Сборка: `./dev build` (или `dev.cmd build`), затем положите
`build/libs/structurecompass-neoforge-1.21.11-1.0.0.jar` в `mods` вашего NeoForge 21.11.48+ — или запустите
`./dev runClient` прямо из проекта.

Автоматически уже проверено: юнит-тесты (`./dev test`), GameTest'ы (`./dev runGameTestServer`) и визуальный
смоук-тест (`./dev runClientSmokeTest` — создаёт мир с сидом `20261109`, делает скриншоты в
`run/smoketest/screenshots`). Ниже — то, что стоит посмотреть глазами.

## 1. Загрузка

- [ ] Игра запускается, в «Модах» есть **Structure Compass** с иконкой (компас и башня), версия 1.0.0, лицензия MIT.
- [ ] В `logs/latest.log` нет ошибок/предупреждений с `structurecompass` / `StructureCompass`.

## 2. Новый мир (Верхний мир)

Создайте мир (креатив, читы включены; для повторяемости — сид `20261109`).

- [ ] Слева вверху появилась панель HUD: сначала «Поиск структур...», через пару секунд — до 5 строк:
      цветной квадрат, стрелка, название, расстояние «N м», под ним `X … Y … Z …`.
- [ ] У ещё не сгенерированных структур вместо Y стоит `~`; у шахт/камер испытаний рядом (в загруженных чанках)
      Y — число.
- [ ] Поворачивайтесь на месте: стрелки в панели вращаются, метки на полосе-компасе вверху сдвигаются;
      «С/В/Ю/З» (ru) или «N/E/S/W» (en) стоят по сторонам света (север — красная буква).
- [ ] FPS не просел (F3 → смотреть FPS до/после `H`).

## 3. Подсветка в мире

- [ ] У каждой ближайшей структуры виден вертикальный полупрозрачный луч и подпись «Название / N м» — сквозь
      блоки и горы.
- [ ] Далёкая структура (за пределами прорисовки): луч и подпись всё равно видны, подпись показывает реальное
      расстояние.
- [ ] Подойдите к шахте/камерам испытаний ближе ~190 блоков: видны контуры (общий — толще, части — тоньше),
      сквозь землю, цветом типа.
- [ ] `J` выключает/включает подсветку (сообщение над хотбаром).
- [ ] `H` выключает/включает HUD. F1 прячет всё.

## 4. Экран структур (`K`)

- [ ] Открывается экран «Structure Compass»; игра не встаёт на паузу (поиск продолжается).
- [ ] Список типов с галочками, под каждым — экземпляры `#1 … м  X … Y … Z …` и кнопки «Следить», «Копировать», «ТП».
- [ ] Поиск: введите «дер» / «village» — остаются деревни.
- [ ] «Показать»: Все → Включённые → Выключенные → Найденные → Не найденные.
- [ ] «Порядок»: по расстоянию / по названию.
- [ ] Снимите галочку у «Заброшенная шахта» → шахты пропали из HUD и из мира; поставьте обратно.
- [ ] «Копировать» → кнопка пишет «Скопировано», в буфере `X Y Z` (или `X ~ Z`).
- [ ] «Следить» → экран остаётся открытым, строка подсвечена жёлтым; закройте экран: под полосой-компасом крупная
      жёлтая стрелка с названием и расстоянием, жёлтый луч в мире. `G` переключает цель по кругу и выключает её.
- [ ] «ТП» (только с читами): телепорт к структуре (для неизвестного Y — на поверхность через `spreadplayers`).
      В мире без читов кнопки «ТП» нет.
- [ ] Переключатель измерения (кнопка справа от «Порядок»): выберите Нижний мир — через пару секунд список
      структур Нижнего мира вокруг соответствующей точки (координаты / 8).
- [ ] «Искать заново» перезапускает поиск (статус внизу: «Поиск... найдено типов: …»).

## 5. Другие измерения

- [ ] Войдите в Нижний мир: HUD показывает крепость, бастион, окаменелости, порталы (без деревень).
- [ ] В Крае (после дракона, на внешних островах): города Края.

## 6. Настройки

- [ ] Моды → Structure Compass → Настройки: разделы «Поиск», «HUD», «Подсветка в мире», «Цвета», «Типы структур»;
      у всех параметров русские названия и подсказки.
- [ ] Поменяйте `Радиус поиска` / `Результатов на тип` → после «Готово» поиск перезапускается.
- [ ] Поменяйте положение HUD (угол), масштаб, ширину полосы-компаса — применяется сразу.

## 7. Чужой сервер

- [ ] Подключитесь к серверу без мода (или к ванильному): одно серое сообщение в чате
      «Structure Compass: на сервере нет Structure Compass…», никаких ошибок, HUD не появляется, `K` пишет, что недоступно.

## 8. Модовые структуры (по желанию)

- [ ] Добавьте мод/датапак со структурами: они появляются в списке с читаемыми именами (`Some Mod Tower (somemod)`)
      и находятся так же, как ванильные.
